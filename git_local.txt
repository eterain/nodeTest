Git의 기본 개념은 다음 6가지.

    Repository : 프로젝트 저장소
    Commit : 작업 기록 저장
    Branch : 작업 분기
    Merge : 브랜치 병합
    Clone : 저장소 복사
    Pull / Push : 서버와 동기화

다음 과정은 Git을 사용할 때 가장 기본이 되는 작업 흐름입니다.

    Git 설치 여부 확인
        git --version
    Git 사용자 정보 설정
        git config --global user.name "eterain"
        git config --global user.email "bigbody@nate.com" : github에 등록된 이메일
        등록오류시 삭제하는 방법 : git config --global --unset user.name        
        특정 프로젝트(폴더)에 다른 사용자정보사용시
            git config user.name "xxxxxx"
            git config user.email "xxxx@xxxx.com"
    Git 저장소 생성
        git init : 생성하고자하는 폴더에서 실행
    Git 상태 확인
        git status
    파일을 Git에 등록 (Staging Area에 추가)
        git add hello.js 
        git add file1.txt file2.txt     
        git add .                    : 모든 파일 추가

        Staging Area 개념
            Git에는 다음과 같은 작업 단계가 있습니다.

            Working Directory
                    ↓
                Staging Area
                    ↓
                Repository
            각 단계의 의미는 다음과 같습니다.
                Working Directory : 현재 작업 중인 파일 공간
                Staging Area      : Commit을 준비하는 공간
                Repository        : Git 기록이 저장되는 공간
    변경 내용을 Commit으로 기록
        변경 내용을 간단하게 설명
        무엇을 수정했는지 명확하게 표현
        짧고 이해하기 쉬운 문장

        git commit -m "hello.txt 파일 추가"

        Commit을 통해 다음 작업이 가능합니다.
            변경 기록 관리
            이전 상태로 복구
            협업 시 변경 내용 확인
    Commit 기록 확인
        git log
        git log --oneline : 간단하게 확인시

        어떤 작업이 언제 이루어졌는지 확인
        이전 변경 기록 확인
        협업 중 다른 개발자의 작업 확인
        특정 Commit으로 되돌릴 때

    파일 수정 후 다시 Commit

일반적인 Git 작업 흐름은 다음과 같습니다.
    파일 생성 또는 수정
        ↓
    git status
        ↓
    git add
        ↓
    git commit
        ↓
    git log

Git 기본 명령어 정리
    명령어	설명	        예시
    git --version	        Git 설치 여부 및 버전 확인	git --version
    git config --global user.name	Git 사용자 이름 설정	git config --global user.name "홍길동"
    git config --global user.email	Git 사용자 이메일 설정	git config --global user.email "hong@example.com"
    git config --list	Git 설정 정보 확인	git config --list
    git init	현재 폴더를 Git 저장소로 초기화	git init
    git status	현재 Git 저장소 상태 확인	git status
    git add 파일명	특정 파일을 Staging Area에 추가	git add hello.txt
    git add .	모든 변경 파일을 Staging Area에 추가	git add .
    git commit -m "메시지"	변경 내용을 Commit으로 저장	git commit -m "파일 수정"
    git log	Commit 기록 상세 확인	git log
    git log --oneline	Commit 기록 간단히 확인	git log --oneline
